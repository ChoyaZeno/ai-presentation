# Clear Ideas Presentation

A four-slide deck built with `flutter_deck` and the CZ theme and components from
the local Widgetbook design system.

The sibling `../CZ-Online-Apps-ServiceApp` checkout is required for the local
Widgetbook and shared-component dependencies.

## Run

```sh
flutter pub get
flutter run -d chrome
```

Navigate with the arrow keys or the presenter controls. Swipe gestures are
enabled on mobile.
