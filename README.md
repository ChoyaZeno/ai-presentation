# Multi-Agent Brainstorm Presentation

A 17-slide presentation about the `multi-agent-brainstorm` skill, including its
Gherkin documentation workflow, a live demo run sheet, and an interactive game.
Built with `flutter_deck` and the CZ theme and components from the local
Widgetbook design system.

The sibling `../CZ-Online-Apps-ServiceApp` checkout is required for the local
Widgetbook and shared-component dependencies.

## Run

```sh
flutter pub get
flutter run -d chrome
```

In VS Code, select **AI Presentation (Chrome)** in Run and Debug and press F5.

Navigate with the arrow keys or the presenter controls. Swipe gestures are
enabled on mobile.
